## [Source Import] - 2026-05-09

### Added
- Imported the Mini vMac source code as the initial upstream codebase.
- Preserved the original GPLv2 licensing material.
- Established Mini vMac as the starting point for 68kBox development.

### Notes
- This import is the foundation for the initial work.
- No Macintosh ROMs, Apple system software, disk images, or commercial software are included.
- The immediate goal is to preserve Mini vMac behavior and provenance before modernizing structure, build process, or architecture.

## [Initial Repository Setup] - 2026-05-07

### Added
- Created the `68kBox` GitHub organization.
- Created the initial 68kBox repository.
- Added a minimal one-line `README.md`.
- Added a copy of the GNU General Public License version 2.

### Notes
- The repository was created before the Mini vMac source import.
- The project is intended to begin as a preservation-oriented fork/import of Mini vMac, focused first on stabilization and maintenance.
